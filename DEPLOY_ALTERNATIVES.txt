SoloPulse — Netlify 크레딧 없을 때 대안 (무료 위주)
================================================

Netlify 빌드 크레딧이 소진되면 새 배포가 멈춥니다.
이미 올라간 사이트는 남을 수도 있지만, 업데이트·재빌드가 막힙니다.

아래는 당장 쓸 수 있는 방법입니다. 추천 순.

────────────────────────────────────────
★ 1) Vercel (가장 추천 · Next.js 공식 호스팅)
────────────────────────────────────────
  · 무료 Hobby 플랜: 개인 프로젝트용으로 Next.js + API 라우트 지원
  · 사이트 예: https://solopulse.vercel.app (이름 선택 가능)
  · 배포 방법:

    A) 이 PC에서 (권장)
       1. deploy-vercel.bat 더블클릭
       2. 브라우저 로그인 창 뜨면 Vercel 계정 로그인
       3. 끝나면 Production URL 출력

    B) 명령어
       npx vercel login
       npx vercel --prod

    C) GitHub 연동
       github.com 에 푸시 → vercel.com Import → 자동 배포

  · 보드 실측: Netlify와 동일
    집 PC start-miner-tunnel.bat → trycloudflare URL 을 기기 칸에

  · 한도: Hobby는 상업용·팀 제한 있음. 개인 솔로 대시보드면 보통 충분.

────────────────────────────────────────
★ 2) 집 PC 영구 공개 (완전 무료 · 크레딧 0)
────────────────────────────────────────
  이 PC를 서버로 쓰고 Cloudflare 터널만 켭니다.
  Netlify/Vercel 없이도 전 세계 HTTPS 접속 가능.

    start-solopulse.bat
      → localhost:3000 서버 + 공개 trycloudflare URL

  · 장점: 같은 Wi‑Fi면 기기 LAN IP(172.x) 바로 연결
  · 단점: PC 전원이 꺼지면 사이트도 꺼짐
  · 터널 URL은 재시작 시 바뀔 수 있음 (창에 나온 주소 사용)

  Windows 시작 시 자동:
    작업 스케줄러에 start-solopulse.bat 등록
    또는 scripts\install-permanent-tunnel.ps1 (채굴기 터널)

────────────────────────────────────────
3) Cloudflare Pages (무료 티어 큼)
────────────────────────────────────────
  · OpenNext 어댑터 필요 · 설정이 Vercel보다 복잡
  · 관심 있으면 나중에 세팅 가능

────────────────────────────────────────
4) Render / Railway / Fly.io
────────────────────────────────────────
  · 무료·저가 티어 있음 · 슬리프(잠듦) 있는 경우 많음
  · Next 풀스택은 Vercel이 더 단순

────────────────────────────────────────
보드 해시가 Netlify/Vercel에서 안 되는 이유 (공통)
────────────────────────────────────────
  클라우드 서버는 집 공유기 172.x / 192.168.x 에 접속 불가.
  → start-miner-tunnel.bat 으로 채굴기만 공개 터널
  → 또는 방법 2(집 PC 서버) 사용

────────────────────────────────────────
지금 바로
────────────────────────────────────────
  Netlify 없이 업데이트하려면:
    deploy-vercel.bat

  크레딧 0원으로 지금 당장:
    start-solopulse.bat  → 터널 URL로 접속
